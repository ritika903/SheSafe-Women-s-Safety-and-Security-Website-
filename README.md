# SheSafe - Women's Safety Website

## About Project
SheSafe is a women's safety awareness website created using HTML5.

The main aim of this project is to spread awareness about women's safety and provide useful emergency information.

## Technologies Used
- HTML5

## Features
- Home Page
- Women's Safety Tips
- Emergency Helpline Numbers
- Self Defence Awareness
- Contact Us Form

## Project Structure
- index.html
- safety-tips.html
- emergency.html
- self-defence.html
- contact.html

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
